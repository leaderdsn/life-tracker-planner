# Расписание

Семейное расписание занятий: кто, где и когда, напоминания и отметки о выполнении.
Помогает держать под контролем планы на день, неделю и месяц.

**Открыть:** https://leaderdsn.github.io/life-tracker-planner/

## Возможности

- Вкладки «Все» и отдельная вкладка для каждого участника.
- Виды «День», «Неделя» и «Месяц», переход по датам.
- Таблица всегда упорядочена по времени: строки строятся из занятий. Удалили последнее занятие в 14:00, и строка исчезла. Добавили занятие в 07:15, и строка появилась на своём месте.
- Время можно вводить как удобно: `8.30`, `8,30`, `830`, `8 30` превращаются в `08:30`.
- Добавление участника в два шага: имя и цвет, затем его занятия (можно пропустить).
- Подсветка текущего и следующего занятия, пересечений по времени и мест, которые стоит проверить (значок «?»).
- Отметка «выполнено» и прогресс за день, неделю и месяц по каждому участнику.
- Напоминания за 5–60 минут до начала и в момент начала, тихие часы.
- Резервная копия в JSON, восстановление исходного расписания.
- Светлая и тёмная тема, работает на телефоне, можно установить как приложение.

Данные хранятся в браузере (localStorage). Для связи нескольких компьютеров используется Firebase (необязательно).

## Роли: администратор и гость

**Администратор** — основной режим: редактирование расписания, участники, настройки.

**Гость** — экран для отдельного монитора (в том числе сенсорного):

- только сегодняшний день, крупные часы и дата, колонка на каждого участника;
- нажатие на имя показывает расписание одного участника; без действий экран через минуту возвращается к «Все»;
- за 30 минут до занятия карточка мигает и звенит, пока её не нажмут — тогда она помечается «увидено»;
- администратор видит, что у гостя звенит, и может отключить сигнал со своего компьютера.

Время сигнала, время возврата к «Все», звук, громкость и PIN настраиваются у администратора:
**Настройки → Гостевой экран**.

Как включить гостевой экран:

1. У администратора: **Настройки → Гостевой экран → Включить синхронизацию**, скопировать ссылку.
2. На втором компьютере открыть эту ссылку и один раз нажать на экран — включится звук, полноэкранный режим и запрет на засыпание экрана.
3. Компьютер запомнит режим гостя. Чтобы выйти, удерживайте правый верхний угол 3 секунды и введите PIN.

Совет: для монитора на стене удобно запускать Chrome в режиме киоска:
`chrome --kiosk "https://leaderdsn.github.io/life-tracker-planner/#/guest?h=…"`.

## Участники

Каждый участник может открыть расписание на своём телефоне или планшете:

1. Администратор открывает участника (вкладка с его именем → настройки участника), задаёт PIN и нажимает **Пригласить** — ссылка копируется.
2. Участник открывает ссылку, выбирает себя и вводит PIN. Устройство запоминает вход.

Участник видит только своё расписание и свой прогресс, может отмечать выполненное, выбрать свой сигнал и загрузить аватар.
Его сигнал звучит и в напоминаниях на его устройстве, и на гостевом экране для его занятий.
Сменить пользователя: **Настройки → Выйти** (у участника) или **Настройки → Сменить пользователя** (у администратора, вход обратно по PIN).

PIN защищает от случайных изменений, а не от взлома: это семейное приложение.

## Синхронизация (Firebase)

Без настройки приложение работает на одном компьютере. Чтобы связать администратора и гостевой экран на разных компьютерах:

1. Создайте проект на [console.firebase.google.com](https://console.firebase.google.com) (тариф Spark, бесплатно).
2. **Security → Authentication → Sign-in method** — включите **Anonymous**.
3. **Databases & Storage → Realtime Database → Create Database** (регион europe-west1), режим **locked**.
4. Вкладка **Rules** — вставьте содержимое [database.rules.json](database.rules.json) и опубликуйте.
5. **Project Overview → + Add app → Web (`</>`)** — зарегистрируйте приложение и скопируйте конфиг.
6. Для локального запуска создайте `.env.local` по образцу [.env.example](.env.example).
7. Для сайта на GitHub Pages добавьте те же значения в **Settings → Secrets and variables → Actions** репозитория
   (`VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_DATABASE_URL`, `VITE_FIREBASE_PROJECT_ID`, `VITE_FIREBASE_APP_ID`)
   и перезапустите workflow **Deploy**.

Ключи веб-конфига Firebase публичные по своей природе. Доступ к данным ограничен правилами базы и длинным секретным кодом семьи в ссылке — не публикуйте ссылку гостевого экрана.

### Про напоминания

Уведомления приходят, пока приложение открыто во вкладке или запущено как установленное приложение.
Push-сервера нет, поэтому при закрытом браузере напоминания не придут.

## Запуск

Нужны Node.js 22+ и pnpm 11+.

```bash
pnpm install
pnpm dev          # http://localhost:5173
```

| Команда | Что делает |
|---|---|
| `pnpm dev` | режим разработки |
| `pnpm build` | проверка типов и сборка в `dist/` |
| `pnpm preview` | просмотр собранной версии |
| `pnpm test` | unit-тесты (Vitest) |
| `pnpm lint` | ESLint |

## Деплой

Сайт публикуется на GitHub Pages workflow-ом [.github/workflows/deploy.yml](.github/workflows/deploy.yml) при каждом push в `main`.
Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**.

## Стек

Vue 3, TypeScript, Vite, Pinia, Vue Router, PrimeVue, Sass, Vitest. Архитектура: Feature-Sliced Design.

## Структура

```
src/
  app/        инициализация, роутер, стили
  pages/      страница расписания
  widgets/    шапка с вкладками, неделя, день, месяц, прогресс
  features/   добавление участника, редактирование занятия, отметки, напоминания, импорт/экспорт
  entities/   расписание: типы, стор, чистые функции
  shared/     время, текст, базовые компоненты
```
